# Contributing

Please open an issue for bugs and feature requests. Include operating system,
application steps and sanitized error messages. Never attach API keys or private
EEG recordings. Use the bundled public samples when reproducing a bug.

Code contribution terms are pending the application license decision. Discuss
non-trivial changes before submitting them. For local development, follow README,
run the automated backend tests and build the frontend. Scientific algorithm
changes need domain-specific evidence beyond UI and API tests.
